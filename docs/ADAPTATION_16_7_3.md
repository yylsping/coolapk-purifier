本地开发及验收，不代表远程发布授权。

## 目标审查

原始 APK 是壳，实际运行后读取并恢复 10 份业务 DEX，共 95,169 个类。
单独加载的 SDK DEX 未混入业务解析输入。生成器明确使用 16.7.0 作为 baseline；
有歧义的结果另行核对布局静态字段、数据字段、binder cast、完整签名及调用链。

保留五版原有十五个目标的内容，为六版分别加入 `hostUpgrade`。16.7.3 的原有
十五个目标中，七个不变、八个变化；加上新功能后，每版为十六个目标。

确认其 scalar 工厂为 U+0795，未借用其他版本填补缺失证据。

## 新底栏契约

16.7.3 保留十五参展示入口，但内部改为通用玻璃导航组件：

- 展示入口：`liquid.U+037F.U+052C`；配置 `w09`、条目 `el`、发布槽 `h19`。
- 通用玻璃入口：`vt1.U+0588`，十八参；内容 lambda：`vt1.U+0529`，十五参，
  返回 `kotlin.Unit`。它们与旧版的 owner、参数次序和返回类型不同。
- 原生光学二十项、布局八项与返回布局的字段语义逐项核对；展示列表、点击
  映射和发布位置仍投影到原生组件，不替换 shader、手势或逻辑页面列表。
- 新版会将无效选中位置折回首项。隐藏当前页面时，单独中和选中镜片的光学
  与颜色，并让两层内容捕获使用普通内容色；发布 lambda 保留自己的强调色。
  切回可见页面恢复原生选中镜片与颜色。
- 可重组列表带归属标记，原生后续重组继续处理正确的页面。Compose changed
  flag 按新入口调整，避免保存的捕获内容残留错误高亮。
- Release 必须保留宿主 `Function5 / Function6` 名称，与既有 `Function0 / 1`
  和 `Unit` 规则一致。实机已捕获并修复 R8 改名导致的契约拒绝，不能仅凭
  Debug 构建确认可用。

旧版分支继续使用原契约；16.6.1 的九参入口与十项光学分支保留。
