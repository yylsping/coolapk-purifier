模块版本为 `2.8.0` / versionCode `20`。本次在 16.7.0 人工验收的基础上，
将第 11 项净化功能“精简底部导航”扩展到其余四个已支持版本；其下五个

当前交付对应文末“设置页布局收尾”记录；下文完整五版本矩阵为此前候选包的验证记录。

## 16.6.1 的独立契约

16.6.2 及以后使用十五参展示入口、十六参玻璃入口、十八参内容入口，光学
参数为二十个 float。16.6.1 则使用 `zb8.U+0786` 九参展示入口、U+0790
十二参玻璃入口，以及独立 `LiquidGlassTabPanelKt.U+07A3` 十三参 panel。
它的十八参内容入口位置也不同，不能按新版偏移解释。

- 配置多一个 `navigationBarHeight`，投影时保留原值。
- ViewModel 的列表 getter / 当前项 getter / 数据构建方法分别为 U+0529、
  U+052A、U+052D；其余版本分别为 U+052A、U+052B、U+052E。
- 光学参数只有十项；颜色对象、能力覆盖对象的字段和构造器也分别少一项。
  通过独立 panel 签名核验，任一条件不符即保留原生底栏。
- 隐藏页面成为当前页时，保留容器的 backgroundBlur / backgroundLens 和
  原生按压几何，只取消选中镜片的高亮、thumbLens 与阴影。普通内容由原始
  配置和原生未指定颜色分支绘制，发布仍使用原始强调色。
- 所有投影调用一致处理 Compose changed flag 和默认颜色，避免可见页与
  隐藏页往返时改变 remember 槽位顺序。

16.6.1 的容器与镜片共用高亮／阴影参数；在“当前页已隐藏”的特殊状态下，
这些共享效果会一起中和，保留背景模糊和折射。切回可见页后恢复完整原生样式。
16.6.2 至 16.7.0 的二十项光学属性及八项布局属性已按 Kotlin 属性语义逐项
对照，字段位置一致，未仅凭混淆名或参数数量判为相同。

共同逻辑保留原始五页模型，仅投影原生展示列表，映射点击、刷新和发布位置。
列表归属沿用弱引用身份登记及重组标记。保留发布按钮时的尺寸修正继续使用
原生容器尺寸、内边距和发布尺寸，只重算页面宽度及各槽位位置。
初始原理与失败实验见[16.7.0 研究记录](ISSUE_26_BOTTOM_NAVIGATION_16_7_0.md)。

## 设置页布局收尾：方案 B
