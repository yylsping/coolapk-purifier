# Issue #26：16.7.0 底部导航精简

本页保留首次仅适配 16.7.0 的研究与候选包验证记录。随后经人工验收，正式
2.8.0 已将“精简底部导航”纳入第 11 项净化功能并完成其他支持版本的适配；跨版本实现与最终交付记录见
[2.8.0 适配记录](ADAPTATION_2_8_0.md)。以下“仅 16.7.0”与候选包版本值
均描述首次研究阶段。

目标为酷安 16.7.0（2610291）。新增五个独立隐藏选项，默认均关闭；
至少保留一个页面入口，发布按钮不计入页面。旧版本 profile 不增加此目标。
本次为本地待人工验收的 `2.7.0-issue26`，versionCode 保持 19，便于覆盖
回到正式 2.7.0；未执行远程写入。

## 研究结论

底栏使用 Compose 和酷安自己的液态玻璃控件。原始逻辑顺序为：

| 原始页面 ID | 页面 |
| --- | --- |
| 0 | HOME，首页 |
| 1 | MOBILE_BAR，数码 |
| 2 | POST_BUTTON，发布按钮 |
| 3 | DISCOVERY，发现 |
| 4 | CENTER，我的 |

`MainViewModel` 从导航辅助类 `com.coolapk.market.view.main.navigation.\u037f`
构建五项展示数据；辅助类的 `\u0560():List`、`\u052f(int):PageName` 和
`kua.\u037f(PageName):int` 共同参与原生页面切换。

临时实验用辅助类过滤得到了“首页＋我的”，实机确认原生玻璃可按两个入口
重排。但该方案未用于交付：隐藏页面会使原生预加载“我的”、数码频道设置等
逻辑取得 `-1`，部分调用没有检查边界。

正式实现保留完整逻辑导航和 ViewModel 原始列表，在原生底栏展示边界投影。
只有已经由本次安装的 ViewModel 构造器或原生数据构建方法观察到的五项列表
才进入投影。归属按对象身份以弱引用记录；新数据发出后，仍在被旧重组使用的
列表也保留归属，避免过渡帧突然恢复全栏。演示页不靠内容相等或条目数量猜测。

## 展示和原生目标

精确目标由 `coolapk_target_manifest.json` 的可选 `bottomNavigation` 目标
提供，安装前核对完整签名、构造器、字段类型以及原始页面顺序。
另有 versionCode 2610291 的显式限制；未知版本或缺少目标不安装。

| 目标 | 用途 |
| --- | --- |
| `com.coolapk.market.widget.compose.liquid.\u037f.\u0786` | 底栏展示边界；15 个参数 |
| 同类 `\u0790` | 原生玻璃容器；16 个参数 |
| 同类 `\u0789` | 原生槽位内容；18 个参数 |
| `LiquidGlassTabPanelKt.\u08b3` | 原生槽位尺寸计算 |
| `MainViewModel()` | 记录列表归属；隐藏首页时选择首个保留页面 |
| `MainViewModel.\u052e()` | 数据构建完成后记录新列表身份，不修改原始列表 |
| `SearchAppHeader(Context, AttributeSet)` | 隐藏“我的”时为头像增加设置长按入口 |

投影同时处理列表、选中位置、刷新图标位置、发布按钮位置及点击回调。
例如只保留首页和我的时，第二个显示入口仍调用原始页面 ID 4。
发布按钮保留原生 Function0 回调，既不伪造页面，也不触发发布操作。
Modifier、原生玻璃绘制、动画、模糊、容器折射和手势实现继续由宿主执行。

## 原生固定数量假设

实机发现：保留发布按钮但减少页面后，原生槽位计算会让末项溢出。
反编译和原始 DEX 引用核对表明，原函数只在“四个页面＋发布按钮”时为发布
按钮和间距扣除宽度；其他数量直接平分内容宽度，随后又加上发布按钮宽度。

修正只作用于带本模块归属标记、保留发布且槽位数少于 5 的计算结果。
原函数仍先执行，保留其容器宽度、内边距、内容高度、发布按钮尺寸和可选
槽位索引，只重算普通项宽度以及各项的 left/width：

```text
N = 页面数
G = 与发布按钮相邻的间距数（1 或 2）
T = 总槽位数 - 1 - G
tabWidth = (contentWidth - publishWidth - G*groupGap - T*tabGap) / N
```

保留原生负 tabGap 语义。五项原始布局的公式完全一致，仍直接使用原结果。
几何结果继续构造宿主 `n19`，其拖动、命中检测及玻璃运动共享同一组尺寸。

## 已隐藏页面成为当前页

原生返回键或快捷入口仍能打开隐藏页面。原生玻璃控件没有“无选中项”的
默认状态，会将无效选中位置钳到第一个入口，形成错误高亮。

此时保持原生跳转，只取消选中镜片的颜色、折射、模糊和高亮；容器本身的
光学参数保持。前景与捕获层的普通图标统一使用原生普通文字色，发布按钮
仍使用独立的原生强调色。其他能力等级的颜色覆盖也保留容器颜色并清空
选中颜色。重新选择保留页面后恢复完整原生选中镜片。

这部分通过新建宿主不可变参数对象完成，不修改共享对象。单纯将选中背景
高度设为 0 的尝试会造成图标模糊和发布按钮变色，已弃用。

## Compose 重组约束

原生 restart lambda 会保存投影后的入参。列表标记使其重入时不会再次删项
或再次映射原始页面 ID；下层槽位标记把归属传递到尺寸计算和内容绘制。

涉及参数的 changed flag 在全部本模块调用中采用一致处理。不能只在隐藏
当前页时增加 `Composer.changed()`，否则会改变 remember 槽位顺序。
研究中的一个临时包曾因此出现 `ComposableLambdaImpl` 到 `Function1` 的
转换异常；统一处理后进行了可见页／隐藏页往返和新进程崩溃日志检查。
ThreadLocal 只用于同步调用范围，finally 恢复，不保留定时任务或轮询。

## 配置与访问

- schema 2 增加可选根字段 `hiddenBottomNavigationItems`，使用五位掩码。
  老配置缺字段时为 0，保留已有十项功能选择；不迁移或重启用旧功能。
- 使用现有宿主私有原子存储；写入原因只接受五个明确的枚举值。
  保存失败回滚选择、revision 和待适配状态。
- 设置页的五个开关只在 2610291 可操作。更改后强制停止并重新打开生效。
- 隐藏首页时冷启动选择首个保留页面，跳过发布按钮。
- 隐藏“我的”时，顶部头像的长按打开同一 Activity 所属的配置 Dialog；
  单击仍打开个人主页。未增加模块 Activity、后台服务或权限。
- 所有入口保留时不安装任何导航业务 hook，也不装头像长按。
